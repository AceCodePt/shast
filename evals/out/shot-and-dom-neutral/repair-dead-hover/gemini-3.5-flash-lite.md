## Model reply

When `:hover` is nested inside `root>mid>leaf`'s CSS block without an ampersand, it compiles to a descendant selector (`root > mid > leaf :hover`), which matches hovered children inside the leaf rather than the leaf itself. To apply the hover state to the leaf element when it is hovered, its own CSS block must be edited to use `&:hover`.

ANSWER: root>mid>leaf
