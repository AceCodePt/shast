## Model reply

`floaty` is `position: absolute` but declares no offsets, so it is placed at its **static position** — the spot it would have occupied had it stayed in normal flow. In the DOM it follows `spacer`, a static block that fills the `root` (a 50px-tall `position: relative` container) from y=0 to y=50. The next line box in normal flow would therefore start at y=50, and that becomes `floaty`'s static-position top. This matches the measured `getBoundingClientRect` of `y=50`.
